Formula cheat sheet

Use block variable names: scenes * takes * shotLen. Operators: + − * / ^ % and parentheses.

Percent: x% means x ÷ 100 — so a 15% uplift is cost * (1 + 15%).

Conditionals: if(total > 300, 1, 0), a >= b, a && b, a || b, c ? x : y.

Functions: min max round(x, d) ceil floor abs sqrt pow clamp(x, lo, hi).

        Module 5 · PWA Asset & PNG Icon Pack

        Export your PNG icon pack

        Browsers need raster PNGs for full installability and for Open Graph link previews. This tool renders every required size from the SVG templates using an HTML5 canvas — entirely on your device.

        Ready. Click “Generate” to render the icon pack.

        Where each file goes

        1. Generate, then Download ZIP. It already contains the correct folder layout (icons/… plus apple-touch-icon.png at the root).
        2. Unzip over your project folder so icons/og-image.png, icons/icon-512.png and the others sit next to their SVG sources.
        3. If your hosting domain differs, prefix og:image, og:url and twitter:image in index.html with your absolute HTTPS URL — social crawlers require absolute URLs.
        4. Bump CACHE_NAME in sw.js after adding the PNGs so installed copies cache them.
