    Formula syntax
    • Operators: + - * / ^ and parentheses. Percent suffix: A * 15% = A × 0.15.
    • Comparisons return 1 or 0: < > <= >= == !=, combine with && / ||.
    • Functions: if(cond, a, b), min, max, round, floor, ceil, abs, sqrt, clamp(x, lo, hi).
    • Example: if(A > 3, A * B, A * B * 1.2). Inputs set as % are stored as fractions (5% = 0.05).
